# P9.I1 implementation note — 2026-08-30

Status: IMPLEMENTED. No verification or acceptance claimed.

## Delivered

- Added a parameterized local-stack launcher with `start`, `stop`, `reset`,
  `add-instance`, and `status` package commands.
- Instance id deterministically owns a port block, local Convex SQLite/object
  storage, environment files, deployment selector, and PID record. Three
  standing instances are documented and tested; the mapping supports N.
- First start uses the official local `convex dev` flow, pins both Convex ports,
  synchronizes an explicit backend env allowlist, then starts health-checked
  Next.js and Hocuspocus processes. Startup fails on missing credentials,
  occupied ports, unexpected deployment ports, or a failed service.
- Added the complete local env template and runbook, including data locations,
  N≥3 commands, safe reset, Bridge setup, and `local-deploy-n` lease protocol.
- Bridge now requires `SPECTRA_CONVEX_URL`, validates http(s), accepts loopback,
  and ignores old journal/cloud fallback state. Boot diagnostics explicitly
  understand local selectors/URLs.
