# Spectra definitive programme

`SPECTRA_DEFINITIVE_TRANSFORMATION_PLAN.md` at the repository root is the canonical product and engineering plan. It supersedes conflicting guidance in `docs/spectra-rebuild/` while retaining those files as historical implementation evidence.

Execution order is Phase 0 through Phase 16. A phase is complete only when its implementation, code-only verification, exit criteria, traceability entries, migrations, and applicable architecture invariants are satisfied in `07_GOAL_CHECKLIST.md`.

Browser, screenshot, video, and Playwright verification are prohibited by the canonical plan. Visual review remains an external user acceptance step after the code-only release gate.
