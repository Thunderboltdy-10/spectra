## Method

Work through the product in this order, one area at a time, using the PLAYBOOK loop (enter realistic state → exercise thoroughly → capture key states incl. intermediates → inspect fully → fix → move on). Update STATE.md continuously — every surface you finish gets its entries VERIFIED or its defects fixed/queued.

1. **Shell deep pass:** sidebar (expanded/collapsed/long names), global search (actually search and open results), notifications, settings surfaces, session persistence stress (Flow 10 variants), desktop stress states (1366×768, narrow panels, 2–4 tiles, work+thread+inspector, dense Library, long titles).
2. **Every work type, deeply** (campaign §11 lists per-type expectations): Document, Flashcards, Quiz, Code, Presentation, Sheets, Board, Plan, Agent. For each: primary workflows, edge states, empty/dense/read-only, comments/history/references/sources, AI read + AI edit, side-panel + tiled layouts. Judge each editor as if it were the product's main selling point.
3. **Conversations & AI quality** (campaign §13): conversation battery (factual/analytical/math/multilingual/multi-turn), research (simple/verified/deep — judge query quality, source diversity, citations), attachments (PDF/image/DOCX/PPTX/XLSX), create-every-type-with-AI, edit-every-type-with-AI, cross-work reasoning, interactive questions/approvals, stop/retry at every stage, failure recovery.
4. **Calendar & School** (campaign §12): views/layers/drag/resize/unscheduled lane/Plan links; ManageBac breadth with Profile P — classes, deadlines, timetable, resources, sync freshness, honest partial states.
5. **Agents:** Foundry end-to-end (create → evidence → skills → publish → use → improve), catalog, routing.
6. **Admin/Analytics/Superadmin:** every metric real or honestly-stated, filters work, tables readable.
7. **Round Two:** after the full pass, re-run everything fresh from reload — all Golden Flows plus one free-use session (campaign §20.5: use Spectra for a real multi-artifact project for an extended session and fix every hesitation you feel).
