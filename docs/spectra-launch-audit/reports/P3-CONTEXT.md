# P3 context: "the AI sees what I gave it" — findings ledger

Scope: every context input traced from the UI to the model prompt and on to what the AI can act on. That covers the open artifact and its selection, attachments, library works, embeds and `contextPolicy`, sources, memory, school and timetable data, thread history, and compaction. Branch `p3/context` from `main` afe74633.

All tracing was done by reading code and running offline tests with mocked Convex, live-room and model seams. No browser, provider, Convex or gateway was used. Every behaviour fix has a test that failed before the fix and passes after it.

## Reported, not fixed

- **No path carries an editor text selection to the AI.** Only the `work:root` context source is registered (`artifact-studio.tsx:2632`), so the picker cannot offer a paragraph, cell or slide the user selected. Registering region sources belongs to the editors agent. Once they exist, fix 8 carries them through.
- **Region claims, studio side.** `artifact-studio.tsx` (~3610) and `region-controller.ts` still render or handle `paused`. Both belong to the editors agent. `convex/schema.ts:3433` keeps the literal for old rows.
- **Owner's private timetable layers.** `spectraArtifacts:get` projects them away for every viewer. The AI sees them only through the live-room overlay (fix 1). When the room is unreachable, the owner's AI sees the shared projection. The projection lives in the Convex privacy helpers, which are not owned here.
- **Agent usage settlement after a takeover** (`settleAgentInvocation`, `convex/spectraRuns.ts`) still uses one worker's usage figure. Fix 10 clears the stored usage at takeover. If the new worker then fails with no usage and has never sent a heartbeat, settlement sees none. The plain run meters are correct.
- **`conversationMemory.originInstructions`** (`gather.ts`) holds the first two user messages among the latest 32, not the thread's origin. It is never passed to the orientation, so it has no effect on the model today.
- **`continuedTraces` in `gather.ts` is dead.** `spectraThreads:get` always returns `traces: []`.
- **A spreadsheet over 64 KB** still returns 8 cells per sheet plus the addresses requested (`bounded-artifact-read.ts`). The row and column counts are given, so the model can request ranges, but there is no index of occupied cells.
- **Embed `contextPolicy` has no UI.** Every creation path writes `"summary"`, including studio and editor code this agent may not touch. Fix 6 makes the stored policy take effect. A selector belongs to the editors agent.

## Rejected as not real

- **Compaction near 256k** (`agent-context.ts`) labels what it digests, keeps identifiers and revisions, and tells the model to re-read. It is not a silent drop.
- **Cross-user leak through `read_embeds`.** The projection is computed per viewer, with a permission decision, the learner quiz projection and the timetable projection. Fix 6 only narrows it further.
- **Quiz answer key through the live overlay.** Before fix 1, the plain context hydration could have hit it. Fix 1's guard covers both paths, and the test asserts no `correctAnswer` for a reader.

## Needs live verification

- A document edited within the last 30 s, then "summarise what I just wrote": the answer must reflect the unsaved text (live room reachable), and fall back to the saved copy when the gateway is down.
- A chat with 4 attachments (a long PDF, a docx, an xlsx and an image) must name all 4. It must say which ones were only partly read, and the provider bill should show one PDF, not one per Office file.
- Saved memory ("use British spelling") must be applied on the next ordinary request without a `retrieve_memory` call, and a retrieval event must be recorded.
- A thread with a pasted prompt over 8,000 characters: the model must not see it twice. After 20+ turns, "what did I ask first?" must lead to a `read_thread` call.
- `read_artifact` on a 60-block essay, a 300-cell sheet, and a code file over 4,000 characters must return them whole. A document over 64 KB must return the outline, and a follow-up `blockIds` read must work.
- `read_embeds` on a host with a summary embed must return the card and hint without the full snapshot.
- Kill a run worker mid-run and let a second one take over: the school usage totals must equal the sum of both workers' usage.
