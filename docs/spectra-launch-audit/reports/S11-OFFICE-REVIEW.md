## Extension, mirror and replay contract recommendation

1. Retain the existing native package + canonical projection + replica revision/history model. An extension should have schema namespace/version and durable owner identity; its physical ZIP path is not identity. Discover custom XML through relationships, validate the namespace, reject ambiguous duplicates, and update the discovered part in place while preserving unknown nodes/relationships.
2. When an external save removes extension metadata, compare against the last common native revision and canonical owner. Missing metadata alone must not delete a Spectra-only citation handle, chart link or embed. Conversely an explicit deletion/unlink operation must carry a tombstone/owned deletion so later imports cannot resurrect it. If ownership cannot be matched uniquely, preserve both versions and expose a focused conflict; do not guess by text alone.
3. Use retained version/replica metadata for that merge. Do not place the only copy of Spectra semantics in a package extension Office may strip, and do not introduce a second independent sidecar database. HISTORY must pin the native payload and corresponding canonical semantic revision together for reversible native imports.
4. SafeWriter's staged sibling file provides atomic replacement, not an independent persistent mirror. BRIDGE should specify mirror location/lifecycle, original identity, direct-sync opt-in and rename semantics while reusing its journal and authority grants. A library move must not implicitly become a filesystem rename.
5. Queue replay should return a typed pending/claimed/verified/conflicted/failed result bound to operation, target, base and result hash. Claimed is still pending work; verified requires its durable receipt and current truth; failed/conflicted must remain actionable. The `952ef8dc` blanket error is too coarse. Native readback, canonical save and queued write must remain separate outcomes.

## Reviewed tests and evidence limits

The old capability matrix tests run stub bindings and validate declarations, IDs, placements and selected policy invariants. They do not call the native writers, so a green matrix cannot establish end-to-end editing. Existing no-op and exact-part tests are valuable and should remain; fixture harness selection of an editable paragraph is reasonable only when paired with explicit negative tests on protected regions. Whole-document refusal must not be reintroduced to make tests pass.

The S10 switch from raw default equality to intent-aware readback is justified for unrequested defaults; its negative loss assertions should be retained. The preservation-guard test named “lets a preserved part be removed with the thing that owned it” never supplies ownership evidence and therefore encodes the flawed blanket exception. Replace that test contract, not just its expected count. O-R6 is an additional guard contract case rather than proof of an existing animation-writing action.

Historical native evidence is useful but limited: smaller academic DOCX, formal-paper offline output, endnote cycles/renumbering, and the small Bridge close/reopen/lock/retry fixture. The acceptance task itself withdrew any broad multi-user claim. This review did not rerun SDK validation, installed Office, browser/K-bar, AI provider execution, OS crashes, linked Sheets/PowerPoint, macOS or production. No network/database/Convex cost measurements were made here. New runtime acceptance must record web/backend/gateway/Bridge revisions separately.
