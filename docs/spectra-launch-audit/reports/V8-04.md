## Remaining real gates — deliberately not hidden

These are the items that prevent an honest “perfect compatibility” claim:

1. The 200k-cell live collaborative UI entered `Reconnecting`/`The edit is still unsynchronized` during stress. The direct lens opened the package, but normal Physics IA-sized work is the representative supported lane. This is a P0/P1 scalability/collaboration issue, not a reason to mark the stress test green.
2. Full Word field/tracked-change/comment/content-control/bibliography/footnote editing is not proven. Those parts are preserved/read-only or refused where the native package cannot safely be round-tripped.
3. Excel pivots, macros, ActiveX, comments, and unknown advanced parts are preservation lanes, not editable native lanes.
4. The live end-to-end Sheets-range → PowerPoint chart scenario (source value edit, refresh/materialize, native chart revision, pin, source revoke, last-available display, duplicate/local-replica cleanup) is implemented and covered by resolver/writer tests but was not completed as a fresh integrated device run. It must remain a next acceptance gate.
5. The Nigerian religion deck is correctly used as the detailed presentation, but it does not contain charts, hyperlinks, or real notes package parts. Dedicated corpus fixtures cover those features; a future live native-app run should use them when testing those exact families.
6. The browser’s Word-copy export/download interaction timed out in Playwright. The linked source file was not replaced, which is safer, but an end-to-end download/reopen/hash/GUI proof is still required.
7. The pre-existing Live Dock required-input overlay can obscure a page. It is not an Office incompatibility notice. Its automatic collapse and broader status-density treatment need a separate thoughtful UI pass by another agent; this audit intentionally did not redesign that workflow.
8. `doubleSyncRisk: true` remains truthful for the provider-managed OneDrive folder. The Bridge is active and fully synced, but the external provider can widen conflict timing.

No unsupported feature is silently reported as editable in the live UI. Where a feature cannot be safely projected, the native carry remains and the notice is scoped to that region rather than presented as a giant background banner.
