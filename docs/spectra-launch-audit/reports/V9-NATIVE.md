## Integrated path and bounded fixes

**Word.** The document editor's visible `Export Word copy` now requests a saved-content, retained-package materialization through `POST /api/spectra/lenses/docx` with `action: download-copy` for imported native DOCX. The route rechecks artifact read authority through the existing Convex reads, hydrates the durable saved content, verifies the retained payload, applies the same DOCX native operations as linked materialization, reopens the result, checks its semantic digest and protected parts, and returns DOCX bytes with attachment, length, no-store and saved-version headers. It makes no replica, upload or Bridge mutation. A missing base or failed digest returns an error and the editor surfaces it; it cannot silently serve an old package. New Spectra-authored documents retain the existing editable-copy writer. The artifact menu's blob download and the editor's copy action now keep their object URLs alive during browser handoff rather than revoking them immediately. This closes a deterministic download race, but the cause of V8-04's particular Playwright timeout cannot be assigned without its browser request/download trace; it still requires the live rerun.

The linked write path remains separate: saved document content reaches `materializeDocxArtifact` in the DOCX route, then `replicas:queueMaterialization`; a Bridge `bridgeWriteRequests` claim writes the local resource and `bridgeSync:completeWrite` verifies/readbacks and advances its receipt. External Word edits use the DOCX `open`/`reconcile` path and `replicas:recordExternalReconciliation`/activation with three-way conflict refusal. The retained native payload query prefers an active pending payload before the cloud replica. Canonical saved version, queued request, verified local write and reconciled external version are distinct states; the browser copy does not replace a linked source.

**Sheets → PowerPoint.** The presentation `Linked source`, `Refresh chart data` and `Pin the current values` commands bind a stable Sheets range to a chart object. `refreshPresentationLinkedCharts` reads the committed source/version, updates the live chart's categories and series, retains the last authorized chart content if unavailable, and resolves pinned values without a source read. `materializeOfficeArtifact` hydrates those bindings before the PPTX lens writes actual chart caches and embedded workbook cells. The graph clone/removal path gives duplicate slides independent chart/workbook descendants and releases descendants only after their owner is removed. A deterministic defect was fixed: if the named sheet in `Data!A1:C4` vanished while another sheet remained, the resolver previously substituted the active sheet and could show unrelated values. It now reports unavailable and retains the last authorized chart.

The persisted Bridge `native_ack_queue` stores completed local-write acknowledgements and retries by claim lease. Focused Rust tests exercised deduplication/retry and target-hash recovery after a lost acknowledgement. These are deterministic checks, not an observed live queue row or device receipt. Retained ownership and final garbage collection remain subject to the existing retention policy; this preparation did not shorten policy or run collection.
