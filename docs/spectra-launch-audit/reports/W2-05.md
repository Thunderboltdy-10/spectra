# W2-05 — Cross-artifact AI research, spreadsheet analysis, and presentation readiness

## Result

The live production runtime was exercised with the dedicated `launch-w2-05` browser profile and unique fixtures `LA-W2-05`. Spreadsheet cell entry and ordinary reload persistence work: the six-week study/quiz dataset survived a reload and remained independently calculable. The consequential paths do not yet close safely:

- Source-backed document generation reached public-web search and live artifact progress, but the quality gate rejected the operation for missing verified source metadata; the document readback was only the default `Start writing here.` placeholder.
- A vague follow-up in the same conversation could not bind to the just-created document and asked the user to name/select work.
- Adding a chart to a selected sheet range did not persist after reload. Source tracing shows a chart-only update is treated as unchanged by `sameContent`; this is owned by the W2-08 sheets/editor lane.
- The presentation-generation/export scenario was not completed because the shared Convex dependency on port 3002 went down during the audit. The web shell then returned API 500s and the live run paused with “Spectra could not list files in this folder right now.” I did not restart or deploy the shared runtime.

No source files were changed and no commit was created.

### Spreadsheet chart persistence — live fail with source confirmation

Selected range `A1:C7` and invoked the visible chart action. The selection state was visible, but after reopening the same artifact the cell data remained while `document.querySelectorAll('.sheets-chart-object').length` was `0`. The chart was therefore not part of the persisted artifact readback.

The source chain is direct:

1. `createChart()` constructs a `SheetChart` and calls `updateActiveSheet` with `charts: [...sheet.charts, chart]` at `src/features/spectra/components/sheets-studio.tsx:2742`.
2. `updateActiveSheet` calls `commit(...)` at `src/features/spectra/components/sheets-studio.tsx:1968`.
3. `commit` returns early when `sameContent(current, next)` is true at `src/features/spectra/components/sheets-studio.tsx:1930`.
4. `sameContent` at `src/features/spectra/components/sheets-studio.tsx:302` compares active sheet, sheet count, sheet IDs/names, and cells, but does not compare `charts` (or other non-cell workbook state).

This is a source-backed editor finding, not an inference from the visual symptom. It is intentionally not patched in this W2-05 worktree because the parent assignment places the Sheets editor/serialization fix with W2-08.

## Findings grouped by root cause

### W2-05-F01 — Research results do not reach the document as durable verified provenance

- **Severity:** launch blocker for source-backed educational artifacts.
- **Confidence:** high.
- **User consequence:** A teacher-facing brief cannot be trusted as source-backed or exported with durable citations, even though public-web search visibly ran.
- **Repro/code chain:** `web_search` in `plan.ts:3161-3204` exposes result snippets/URLs; the document rubric at `rubrics.ts:964` requires nonempty verified `document.sources`; `buildResearchEvidence` exists but is not on this run-loop path.
- **Evidence:** live search progress, quality failure message, empty source rail/readback in artifact `wx77tj0sdxyxw5t5hnvrrcv2hx8e07ek`.
- **Affected neighbors:** W1-03 source-backed artifact findings; document citation/export and any presentation/quiz flow that claims source-backed output.
- **Bounded remedy:** Insert an explicit research-evidence step after search: fetch/verify bounded source content, persist `SourceRecord` plus evidence spans, bind citation source IDs into the proposed artifact, and make quality failure explain whether the blocker is missing retrieval, missing binding, or invalid citation. Add a create→reload assertion for `document.sources`.

### W2-05-F02 — Rich live document progress is not reflected in final artifact readback

- **Severity:** launch blocker for generated documents.
- **Confidence:** high for the symptom; medium for the exact internal boundary.
- **User consequence:** The run claims 11 blocks and a complete brief, but reopening the artifact shows the default placeholder. A user could believe work was saved when it was not.
- **Repro/code chain:** create the source-backed brief; observe `11 blocks formed in live artifact`; open Library artifact ID `wx77tj0sdxyxw5t5hnvrrcv2hx8e07ek`; read back one placeholder paragraph and no sources.
- **Evidence:** live artifact studio readback and Library entry described above; the related quality gate also failed despite displaying `85/100, required 80`, which is confusing without a blocker-override explanation.
- **Affected neighbors:** document operations, quality rollback, Yjs/Convex artifact persistence, Library open/readback, exports.
- **Bounded remedy:** Add a post-commit verifier that reads the persisted artifact by ID and checks block count/content/source IDs before reporting success; if verification fails, surface `save/readback failed` instead of a completed-progress narrative. Separately clarify the score-versus-blocker message.

### W2-05-F03 — Vague chat follow-up loses the intended artifact target

- **Severity:** important.
- **Confidence:** high.
- **User consequence:** A natural revision request after a generated artifact produces a permission/target clarification instead of a safe edit, even in the same conversation.
- **Repro/code chain:** send the vague revision from chat with `0 context objects selected`; the run cannot bind the document. Directly opening the document supplies one context object, showing that the studio path has the information the chat path lacks.
- **Evidence:** exact failure message and the chat/Library target mismatch described above.
- **Affected neighbors:** W1-03 clarification, Library context chips, chat continuation, edit authorization and artifact ownership.
- **Bounded remedy:** Preserve the focused artifact ID in the conversation/run continuation when the prior turn created or selected exactly one artifact; otherwise ask a concise disambiguation question before execution and show the candidate artifact names. Test that no unrelated artifact is mutated.

### W2-05-F04 — Chart-only sheet changes are silently dropped by `sameContent`

- **Severity:** important; W2-08 owner.
- **Confidence:** high.
- **User consequence:** A user can create a chart, see the action complete, reload, and lose the chart without an error. The same comparison gap may affect other non-cell sheet state.
- **Repro/code chain:** `createChart()` → `updateActiveSheet()` → `commit()`; `commit` returns when `sameContent` compares equal; `sameContent` ignores `charts` and other workbook state. Live reload produced zero chart objects while all cells survived.
- **Evidence:** selected `A1:C7`, chart action, reload readback with chart count `0`; source lines above.
- **Affected neighbors:** W2-08 Sheets persistence, table/format/freeze/merge/conditional-format persistence, AI spreadsheet-to-presentation handoff.
- **Bounded remedy:** Make `sameContent` compare or hash the complete persisted workbook state, or split cell/state commits with a state-aware equality function. Add live tests for chart add/edit/delete and adjacent non-cell mutations, then reload and assert deep state equality.

### W2-05-F05 — Shared Convex outage interrupts active runs and leaves the web shell misleadingly available

- **Severity:** launch blocker for reliable end-to-end runs in this environment.
- **Confidence:** high for the observed outage; low for root cause.
- **User consequence:** The presentation run paused with a generic folder-listing message while API calls and sync failed; the browser still rendered the shell, so the failure was not obvious until inspecting health/console state.
- **Repro/code chain:** port 3002 stopped listening; `/api/health` returned `not_ready` with `Convex did not answer`, `/api/spectra` returned 500, and the browser reported refused Convex WebSocket connections.
- **Evidence:** `runtime-health.json`, `runtime-convex-down.png`, `runtime-convex-down.yml`; no restart was attempted.
- **Affected neighbors:** all AI runs, Yjs artifact sync, Library readback, presentation export, browser smoke tests.
- **Bounded remedy:** Before launching a long audit/run, gate on all dependency health checks. During a run, distinguish dependency-unavailable from local file-list errors and preserve a resumable run state. The shared-runtime owner must investigate why 3002 exited; this task did not have authority to restart it.

### W2-05-F06 — Presentation artifact/export quality remains unverified

- **Severity:** future/untested, not a claimed defect.
- **Confidence:** high.
- **User consequence:** No evidence yet supports the requested PPTX chart labels, alt text, number traceability, overflow safety, or export readability for this fixture.
