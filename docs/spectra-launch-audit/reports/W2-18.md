## Findings

### W2-18-F01 — Native “restore selected” replaced all content

Severity: important before advertising selective restore. Confidence: high; source-confirmed and fixed.

`src/features/spectra/work/models/yjs/native-artifact-model.ts` previously treated metadata-only restore surgically but routed any content selection to `replaceSnapshot(value)`. That full projection could overwrite unrelated current paragraphs, slides, cells, code lines, or whiteboard data, and claimed `artifact:structure` instead of the selected semantic region.

The fix derives current and historical semantic descriptors, rejects path/kind/parent/overlap-domain changes, merges only the selected content paths into the latest live projection after the claim callback begins, applies that merged model through the existing adapter, and forwards only selected metadata fields. A structural selection still uses the existing whole-structure path. The regression test confirms unrelated native content survives.

This is deliberately an adapter-boundary fix, not a new checkpoint protocol or a claim/schema migration. It should be followed by format-specific tests for document rich blocks/table cells, presentation objects, sheet cells, code lines, and whiteboard nodes.

### W2-18-F02 — Durable Yjs replay can be ahead of the artifact/embed projection checkpoint

Severity: high for trust in post-crash readback. Confidence: high; reproduced in an isolated in-process harness.

`persistAcceptedMessages()` durably appends ordinary human updates and updates `liveStateVectorHash`, but native projection checkpointing is queued through the idle/max scheduler. On a crash after append and before checkpoint, room replay reconstructs the new Yjs content. `onLoadDocument()` currently decides whether to call native recovery from the equality of the observed state-vector hash and stored `liveStateVectorHash`. In the crash window those hashes are equal, so recovery is skipped even though `lastProjectionSequence` can be behind `nextSequence - 1`.

The result is a plausible editor/detail state with stale `spectraArtifacts.content`, Library listing metadata, and embed projections until another checkpoint-triggering edit. The test readback is explicit: replayed title `replayed after crash`, stale artifact title `Crash-window probe`, durable head 1, projection sequence 0, and `shouldRecoverNativeRoom()` false.

This was not silently patched as a broad protocol change. The parent should choose one of these concrete designs:

1. On native room load, compare `lastProjectionSequence` with the durable head (`nextSequence - 1`) in addition to the state vector. When vectors match and the projection sequence lags, perform an authorization-checked checkpoint/repair from the replayed projection before returning the document.
2. Make the gateway append path create a durable projection-repair outbox item tied to the exact state-vector/sequence, then make load drain or expose that repair before detail/embed consumers claim convergence.
3. Add an atomic checkpoint acknowledgement that records both the artifact projection hash and `lastProjectionSequence`, then test append → crash → reload → detail/Library/embed convergence with no new edit.

Neighboring checks must cover `scripts/collaboration-gateway.mjs` load/persist paths, `convex/collaborationGatewayStore.ts` append/checkpoint mutations, listing sync, change groups, and `artifactEmbeds.projection`.

### W2-18-F03 — Embed deletion tombstones are integrated; row/node transaction drift remains

Severity: medium for future recovery/retention. Confidence: high for the integrated deletion behavior; medium for the still-unverified row/node race.

W1 commit `8a04e039` includes the W1 embed tombstone fix. `spectraArtifacts.permanentlyDelete` reads both source and container indexes, retains removed rows as tombstones, and cancels pending embed/source access requests. The focused Convex test passes both directions. This task made no change to deletion retention, orphan cleanup, or broad garbage collection; those belong to W2-22.

The remaining source seam is whiteboard reference creation: the Convex `artifactEmbeds` row is inserted before the Yjs node transaction completes. A tab crash or failed local transaction can leave an active row without a visible node; current undo/redo reconciliation only runs when those actions occur. A later isolated interruption test should create, move, undo, redo, delete, restore, and verify row/node reconciliation.
