## Source change

`src/features/spectra/components/sheets-studio.tsx` now compares the complete
normalized persisted workbook model. The equality path covers top-level
metadata, sheet metadata, charts, tables, merge/freeze/visibility state, and
all persisted cell fields. It keeps a reference fast path, uses the existing
changed-cell overlay hint for targeted comparison, and otherwise compares cell
addresses semantically without serializing the workbook on each render.

`workbookIdentityKey` now includes the same complete semantic state, including
non-cell sheet state and chart metadata, with a deterministic mixer and a
WeakMap cache for immutable normalized snapshots. Incoming snapshots check
semantic equality before computing the full identity key.

### W2-08 interrupted XLSX journey

The owned bridge fixture was rebuilt from
`fixtures/office/xlsx/complex-preservation.xlsx` with unique native cell
addresses plus an explicit date cell, hidden row 3, merge `B17:C17`, and frozen
row/column panes. The final source package contained formulas and cache,
`Sheet1`/`Sheet2`, a table, date number format, hidden row, merge, freeze pane,
and native chart/drawing parts.

Through the UI, the strict-native workbook was opened, the external-copy
conflict was resolved with `Keep Excel version`, `A1` was changed from `1` to
`11`, and the formula bar recalculated `=SUM(A1:A5)` to `25`. Undo returned A1
to `1`; redo returned it to `11`. After closing and reopening from Library,
the edit remained (`A1 = 11`, formula result `25`), the date remained
`1/1/2024`, and the imported freeze state remained active. Switching to Sheet2
and back also worked and exposed the correct active-sheet state.

The native copy was downloaded through More work actions → Download native
copy. Package readback proves this was a retained-package native export rather
than a clean Spectra-only copy: chart, drawing, table, styles, workbook,
worksheet, merge, hidden-row, and freeze parts all remained present. The
downloaded package has `A1 = 11`, date `2024-01-01`, `mm-dd-yy`, `Table1`, and
the original chart parts.

The remaining fidelity issue is exact and actionable: the downloaded formula
cell is still `<f>SUM(A1:A5)</f><v>15</v>` even though `A1` is `11`; ExcelJS
readback reports cached formula result `15`, while the reopened Spectra editor
derived result `25`. Parent integration should retain this as a native
readback gate and decide whether the retained-package writer must refresh
formula caches or explicitly mark them stale.
