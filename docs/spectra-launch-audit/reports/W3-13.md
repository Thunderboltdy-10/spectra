## Findings grouped by root cause

### W3-13-F01 — vulnerable Next/Convex baseline

Severity: launch blocker before this patch; confidence high.
Baseline chain: Next `16.2.9` was in current Next advisory ranges and brought vulnerable PostCSS/sharp resolutions; Convex `1.41.0` depended on nested `ws@8.20.1`. The user consequence was exposure to framework RCE/DoS findings and fragmented-frame memory exhaustion on a package path used by Convex. The bounded remedy is the reviewed Next `16.3.4` and Convex `1.45.0` upgrade. Neighboring Clerk, App Router, Convex helper, identity, storage, bridge and collaboration tests passed.

### W3-13-F02 — helper peer drift

Severity: important; confidence high.
`convex-helpers@0.1.123` declared a Convex peer beginning at `^1.43.0` while the app resolved `1.41.0`. This did not require an override; aligning both to Convex `1.45.0` and helpers `0.1.124` makes the declared contract true. `npm ls` and Convex-focused tests pass.

### W3-13-F03 — stale PostCSS override defeated the framework patch

Severity: important; confidence high.
The existing `^8.5.10` override resolved PostCSS `8.5.15`, even though Next `16.3.4` declares `8.5.23`. That left PostCSS advisory paths present after a framework-only upgrade. Setting the existing override to exact `8.5.23` resolved the package and nested `nanoid@3.3.18`; build and lint pass. This is a targeted compatibility override, not a ws advisory suppression.

### W3-13-F04 — remaining dependency advisory tree

Severity: launch gate for affected paths; confidence high from refreshed npm audit.
Remaining package nodes are:

- `@ai-sdk/react`, `ai`, `@ai-sdk/provider-utils`, `@ai-sdk/gateway` — provider-utils uncontrolled resource consumption (`GHSA-866g-f22w-33x8`), reachable from AI run code.
- `@tiptap/core` — prototype-pollution/XSS and Markdown ReDoS (`GHSA-cp6q-959q-f8rh`, `GHSA-j95f-988m-3j2f`), reachable from document editors.
- `mammoth -> @xmldom/xmldom@0.8.13` — ten XML injection/DoS advisories, reachable from DOCX intake.
- `exceljs@4.4.0 -> uuid@8.3.2` and its `archiver` tree — uuid bounds and brace-expansion advisories, reachable from XLSX intake/export support.
- `pptxgenjs@3.12.0 -> image-size@1.2.1` — `GHSA-w3rx-r6r6-pgpr` and `GHSA-5p2g-fcmc-qvqq`; the audit has no safe image-size release and proposes a major-shaped PPTXGenJS resolution.
- `pdfjs-dist` — arbitrary JavaScript advisory `GHSA-hq66-cqwq-w95`, reachable from server extraction and browser/library PDF readers.
- `@lobehub/ui -> mermaid@11.15.0`, `query-string@9.4.0 -> decode-uri-component@0.4.1`, `@lobehub/ui -> leva -> colord@2.9.3`, `jspdf -> dompurify@3.4.11`, and `docx -> nanoid@5.1.15` — remaining UI/parser support paths.
- `next -> baseline-browser-mapping@2.10.38` and `nodemailer@9.0.1` — remaining moderate/high audit nodes.
