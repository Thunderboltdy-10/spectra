The patch preserves the existing Yjs-backed Sheets and native-emission paths while addressing the scoped launch risks:

- Added an authoritative semantic Sheets comparator. It compares workbook/sheet metadata and cell fields directly, uses changed-cell address hints when available, and does not use a whole-workbook hash or sort/serialize the entire workbook on every edit. Chart/table/name/dimension/style metadata changes remain observable even when cell maps are shared.
- Replaced the old whole-workbook FNV identity path in `sheets-studio` with semantic equality and bounded reference retention for stale emitted revisions.
- Added bounded XLSX formula-cache invalidation for native `xlsxLens.applyDelta`: formula text is retained, stale cached values are removed after formula/input edits, calculation properties request recalculation, and format/merge/freeze-only edits do not invalidate caches.
- Updated clean/new ExcelJS export policy so cached-only or stale formulas emit formula text without an invented result while recognized calculated values can still be emitted; workbook calculation properties request recalculation.
- Added one-family native font normalization. PPTX OOXML now serializes `Georgia, Cambria, serif` as native `Georgia` while browser canvas rendering keeps the CSS fallback stack. DOCX uses the same safe native-family normalization.
