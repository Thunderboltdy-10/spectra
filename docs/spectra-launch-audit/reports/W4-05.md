# W4-05 — complete peer sharing and owner publishing flows

## Result

The bounded W4-05 rollup is complete in commit `32376a17605e565b4a745ad4db6e447c52e3e4d5` (`Complete peer sharing and owner agent publishing`). Restricted public links now authorize from the authenticated Convex identity's verified email claim; anonymous unrestricted links remain anonymous, and browser-supplied domains are ignored. The share page preserves the token through the sign-in round trip without putting it in the redirect URL.

The AgentFoundry blocker was a stale capability-state condition, not a teacher-role gate: an owned artifact with an empty hydrated capability array evaluated `false` because of a nullish fallback. The UI now treats server-authoritative ownership as publishable while still requiring explicit `publish` for shared collaborators. The server's meaningful instructions, routing, tool/resource, and current passing-evaluation checks remain unchanged.

This report is patched-worktree evidence. No production deployment, shared Convex push, external link send, or primary runtime mutation was performed.

## Evidence

- `convex/authority.test.ts` now covers verified same-domain access, anonymous restricted denial, wrong-domain denial, unverified-email denial, revocation, expiry, unrestricted foreign read, and absence of `contentHash`, `deviceId`, `mountId`, and `relativePath` from the public artifact projection. - `src/app/api/spectra/public/__tests__/route.test.ts` proves the browser-supplied `viewerDomain` is not forwarded, signed-in requests use `convexQuery`, anonymous requests use `convexPublicQuery`, and unverified/wrong-domain states map to actionable 403 responses.

### Owner publish blocker

- `convex/agent-publish.test.ts` seeds an ordinary `student` membership whose account owns an active agent. Publishing without a current passing evaluation is refused with `AGENT_EVAL_GATE_REQUIRED`; inserting a passed evaluation whose hash matches `agents:evalRuns.currentContentHash` allows `spectraArtifacts:publishAgent` to create release 1 and the release list reads it back as published.
- `src/features/spectra/__tests__/agent-publish-gates.test.ts` covers owned artifacts with empty capabilities, shared read/use artifacts, and explicit shared publish capability.

### Private browser preview

On a private frontend preview at `http://localhost:3115`, a mocked restricted-link 401 rendered `Sign in to open this view`; clicking `Sign in to continue` navigated to `/sign-in?redirect_url=%2Fpublic` and left the 40-character token in `sessionStorage` under `spectra:public-share-return`. The preview checkout has no Clerk environment, so the sign-in page itself returned its existing Clerk-provider configuration error; no claim is made about a completed authenticated browser return.
