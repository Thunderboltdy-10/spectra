## Implemented behavior

- Rich text projection and writeback cover bold, italic, underline, strike, native font family, point sizes, color, Word highlight/shading, Unicode scripts, hyperlinks, paragraph styles, alignment, spacing, indentation, lists, and same-text formatting-only changes.
- Existing table row/column topology is diffed and written natively; cell rich content follows the same projection. Advanced merges/grid geometry remain preserved.
- New Word copies contain rich runs, hyperlinks with external relationships, lists, tables, inline/top-level PNG/JPEG media, alt text, and dimensions. A controlled `DocxAssetResolver` embeds authorized bytes and never fetches cookie-bound URLs.
- Retained native PNG/JPEG drawings support targeted alt text, EMU dimension, and `a:srcRect` crop updates by stable media part. The paragraph/object protection gate still blocks broad mixed-content replacement.
- Native OMML is carried as exact XML through native projection, ordinary import, and copy export. No equation conversion or editing is claimed; newly authored equations receive an explicit compact indication and unsupported note.
- New copies carry the document model's header/footer, paper size, orientation, margins, and column controls into Word section/header/footer parts.
- Unsupported media and unsupported node families produce a compact Word indication plus a conversion note rather than disappearing. Unknown and unrelated retained package parts continue through the existing preservation carry.
- Ordinary imported supported images are converted into editable Spectra image nodes; native equation/read-only boundaries remain protected.

## Shared writer / target / receipt boundary

The shared writer is `src/features/spectra/lenses/docx-adapter.ts`. New packages use `@ariadng/office` scaffolding and direct XML only for rich runs, hyperlinks, exact OMML insertion, and section metadata. Retained packages use `docxLens.materialize`/`mutate`, preserving stable W14 paragraph IDs, media part names, existing relationships, and untouched package parts.

Retained writes continue to use the existing `LensPreservedCarry` payload/base hash and Bridge/native precondition flow; this slice does not invent a second native-write authority or receipt. The adapter returns package bytes plus explicit conversion notes for copy/import results. Canonical save/native-write receipts and causal Bridge reconciliation remain outside W6-03 and belong to the existing lifecycle/Bridge owners.

## Direct neighboring risks and limitations

There was no shared runtime, browser acceptance, Windows Office rendering, or macOS Office/Bridge check in this private task, so package readback is not presented as native Office rendering proof. The existing command registry and document image/page controls consume the shared model, but registered-command reachability, keyboard undo/redo with a concurrent unrelated edit, and causal native receipts still need the later integrated acceptance.

The main remaining material fidelity boundary is equation interchange/editing. Native OMML is now preserved instead of flattened for imported copies, but authored LaTeX/Spectra equations are not converted to OMML. Retained header/footer/section edits and advanced table/Word-part edits likewise remain explicit preserved-only cases.

4. Exercise the registered contextual commands plus keyboard undo/redo alongside an unrelated collaborator edit, recording the operation identity and native-write/canonical-save receipts.
