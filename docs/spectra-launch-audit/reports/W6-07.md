## Delivered

Spectra now exposes one universal, discoverable command bar from the application shell. It opens from the visible trigger or Ctrl/Cmd+K, restores focus on close, supports keyboard navigation, and does not capture ordinary typing. Entries are ranked against the current route and active surface; internal/security commands remain hidden.

The command bar uses the existing typed application command registry and dispatcher. Public commands cover route navigation, new/continued conversations, workspaces, library items, comments, imports, settings, stopping a run, and stopping follow mode. Parameterized commands declare typed text, textarea, toggle, select, destination, and item inputs. Existing confirmation and capability gates remain authoritative.

Authorized search runs bounded artifact and conversation search with an AbortSignal, searches beyond the first conversation page, deduplicates results, and carries compact result metadata into the bar. It does not load thread detail or artifact content until the selected existing command opens the target. Chat continuation uses the existing chat surface and does not create a second panel.

Navigation now has a typed readiness acknowledgement containing action ID, target ID, view, route generation, and status. Requests supersede stale actions by target family, so quick A-to-B-to-A navigation cannot resolve from an obsolete acknowledgement. Mounted workspace, library artifact, calendar, settings, artifact, and conversation surfaces acknowledge readiness at their real mount/data boundaries; slow, missing, denied, closing, or superseded targets resolve truthfully.

Manual pointer, keyboard, and wheel interaction is emitted through the existing choreography host as a typed signal for S6-AI follow disengagement. The command bar exposes distinct Stop current run and Stop following actions. It reuses existing run, follow, import, comment, preference, navigation, and choreography paths rather than adding competing lifecycle or scheduler systems.

## Acceptance journeys

1. From any shell, click Command bar or press Ctrl/Cmd+K; search commands and navigation; bare letters do not open the bar.
2. On Settings, edit a typed toggle/value and execute through the existing preference path; effectful actions retain confirmation.
3. Search an authorized artifact, workspace, or conversation; select it through the existing dispatcher; content loads only after selection and chat remains one conversation surface.
4. Navigate A → B → A quickly; only the current route-generation acknowledgement resolves, while slow/deleted/denied targets report failure or cancellation.
5. With an active run or follow session, the two stop actions remain distinct; manual pointer/keyboard/wheel input emits the existing AI-follow interaction signal.
