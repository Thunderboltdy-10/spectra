The research input identity is now server-issued: `source:<UUIDv4>` for a
source record and `evidence:<UUIDv4>` for an excerpt. A source-backed operation
may carry only those exact handles in `sourceRefs`; URLs and model-supplied
`verified` values do not mint evidence. Attachment inputs retain the original
file identity (`assetId`, `importId`, or client input id), the run id, the exact
execution id, SHA-256, MIME/handling, source map, and extractor provenance.
The deterministic lifecycle fixtures use `upload-1`, `run-real`, and
`execution-1`; retry rekeys the retained row to the newly generated execution
id without copying its bytes.

## Implemented contract

- `web_search` now runs W5's bounded full-source transport after parallel
  search, returning a compact bundle of server-owned source/evidence records.
  It preserves verified versus unverified/partial status, source hashes,
  evidence hashes, page/range metadata where safe, cancellation, cache use,
  three-source concurrency, and the existing source budgets.
- The run captures the research bundle in its context snapshot. Artifact create
  and update operations attach it to `createdFrom.sourceBundle`; content
  references are checked against that exact bundle. Only verified sources with
  matching excerpt hashes become portable citations. Partial or unverified
  sources can remain visible as limitations but cannot be upgraded to a
  verified citation.
- Final verification reads the saved artifact back through the existing
  canonical query and checks the actual blueprint/content, source/evidence
  handles, excerpt hashes/ranges, citation linkage, and evidence presence. The
  existing bounded normalization/apply retry remains available; missing or
  forged research handles fail with a specific error and cannot pass the soft
  complete path.
- Attachments use the existing signed Convex storage upload/intake contract,
  including exact byte count, digest, MIME signature, ownership and receipt
  checks. Scheduled payloads contain no base64. Workers re-read authorized
  signed URLs and reconstruct the existing native image/PDF/Office/text bundle
  only for the model. Retry reuses active retained rows; uploading/quarantined
  or legacy metadata-only rows remain non-retryable and ask for reattachment.
