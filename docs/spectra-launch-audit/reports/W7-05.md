## Implemented behavior

The LaTeX interchange is now a bounded structured parser with deterministic diagnostics and limits for input length, nesting/work, and matrix dimensions. It preserves mathematical structure for grouped cells and `&` separators, `matrix`/`pmatrix`/`bmatrix`, nested `\left`/`\right`, aligned rows, fractions, indexed roots, mixed scripts, common functions/symbols, and sum/integral limits and bodies. Truncated, unbalanced, unknown, or over-budget input is never reported as supported.

The writer emits editable OMML with required properties and slots for fractions, radicals, scripts, functions, n-ary operators, delimiters, matrices, and equation arrays. Equation-array alignment markers are emitted as native ampersand markers and read back as `&`; pmatrix/bmatrix delimiter identity is retained. Native import carries both the exact `ommlXml` subtree and its `ommlSourceLatex`. Unchanged equations reuse the exact subtree; changed supported source regenerates semantic OMML; unsupported native math remains preserved until an explicit replacement is attempted.

The equation command now claims the supported `replace-paragraph` native delta, and focused editor feedback reports the first parser diagnostic while retaining the existing source control and Yjs undo behavior. Insertion into a linked native file and equation placement/alignment property rewrites remain truthfully unavailable.

## Remaining material limits

- This is an intentionally bounded school-math grammar, not a general TeX engine. Accents, bars, braces/box constructs, arbitrary `\operatorname`, and other unsupported syntax remain preserved-only when native and are rejected for replacement with a diagnostic.
- New equation insertion into a linked native file is not implemented; add it in Word or use an unlinked copy.
- `equation.display` and `equation.align` still do not rewrite native layout properties; the source edit path is supported, while those layout changes remain explicitly unavailable.
- Package/parser tests do not prove native Office rendering, real macOS Bridge behavior, or Word visual fidelity.
