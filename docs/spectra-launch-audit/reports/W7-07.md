## Delivered

Spectra’s XLSX route now has native authoring, projection, editing, and reopen/readback coverage for common Excel data-validation and conditional-format rules. The editor model carries list, whole-number, decimal, date, time, and checkbox validations with source/formula metadata, comparison operators, blank/error/prompt metadata, and native range addresses. Common `cellIs`, `containsText`, and two-color `colorScale` rules carry priority and `stopIfTrue`; valid fill/text colors are emitted through native `dxf` records.

The editor-to-native path is wired end to end: native XML projection becomes editor content, content changes become `set-validations` or `set-conditional-formats` deltas, and the native operation writer updates the worksheet XML. Existing unsupported validation nodes and conditional-format rules remain in the worksheet package. Structural row/column range rewriting rebases validation and conditional-format `sqref` ranges. `notBetween` is intentionally preserved as read-only because the current editor model does not represent its inverse range semantics.

Native chart creation and editing now emit real Excel chart parts for combo and histogram charts. Combo charts use the current Spectra semantics of the first series as a column and remaining series as lines on the primary axis. Histograms use `histogramChart`/`histogramSeries`, a native `binCount`, source references, and numeric caches. Chart projections read back plot elements, series references, caches, and combo series types; existing chart edits update the native source references and title through the same writer route.

The Sheets schemas, capability declarations, fidelity map, and studio validation UI were updated to claim the supported native surface while keeping unsupported Excel families preserved. Tests cover materialization, native XML, reopen/readback, range rebasing, unknown-rule preservation, combo/histogram chart parts, and chart edits.

## Unresolved material limits

This is private package/XML, editor-route, and Vitest evidence only. Excel desktop was not launched in this private wave; no native Excel GUI save/reopen was claimed, and no macOS Office check was run. Histogram binning currently follows the editor’s deterministic square-root count bounded to 3–30; there is no user-facing bin-width or secondary-axis control. Unsupported validation and conditional-format families remain preserved rather than editable, and native color-scale readback is limited to the supported two-color editor shape. No shared runtime, browser, Convex/backend, or external device journey was started.
