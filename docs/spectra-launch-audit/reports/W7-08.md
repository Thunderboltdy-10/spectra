## Delivered

- Application commands now use typed payload normalization and explicit
  `completed`, `pending`, `needs-human`, or `failed` outcomes. The typed bus
  retains listener-count compatibility while exposing awaited handler results;
  mounted consumers no longer look successful merely because a listener exists.
- Artifact/thread/page navigation uses existing viewport readiness. Artifact and
  conversation handlers wait for the real target mount; superseded and failed
  acknowledgements remain truthful. Stop-run, stop-follow, cache clearing,
  comments, and Library mutations wait for their domain operation where one is
  available.
- Comments have a canonical direct mutation fallback when no editor is mounted;
  mounted Artifact Studio still owns anchored comment submission. Library
  organizer handlers return explicit successful results after the tree mutation.
- Bridge setup is split from prohibited pairing/trust authority. Human K-bar
  setup/retry commands are available; AI may use the low-risk setup handoff and
  receives `needs-human` for pairing, folder grants, or write-enabling consent.
  A single action identity is retained and replayed once when the Devices
  settings surface mounts. No consent is synthesized.
- `setup_bridge` is registered as the bounded AI handoff tool and emits the
  existing UI-event/choreography path. The prohibited `pair_bridge` and trust
  mutation capabilities remain prohibited.
- K-bar search includes authorized conversations beyond the first page and
  contextual application actions/settings. Selected command parameters are the
  only fields collected; direct comment text uses the compact textarea flow and
  errors are translated into user-facing messages.
- The crowded workbench allocator now includes the chat browser as the lowest
  priority secondary pane. It collapses to an overlay before the editor,
  Library, or live thread/run surfaces, retains width intent, and exposes a
  clear reopen path. `/chat` continues to use its single conversation surface.
- The Settings Vitest environment now supplies a guarded `matchMedia` fixture.
