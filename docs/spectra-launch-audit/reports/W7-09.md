The journey now covers ordinary student ManageBac onboarding and return, verified/no-match/ambiguous identity states, first class catalogue, selection persistence, manual sync progress/error/retry, and later changes through School settings. Selection saves through the existing route with an expected selection revision and returns a concrete `selection_saved` result containing selected/deselected records, retention, materialization, and release outcomes. Explicit deselection offers:

- **Keep in Spectra** — preserves personal notes, completion, schedule, reminders, and links while stopping new school updates.
- **Archive in Spectra** — archives only the Spectra class projection; the provider source is not deleted or changed.

Reselecting a class reactivates the local workspace and planner projection. The existing source-linked task/calendar model remains the owner of personal scheduling intent, source due dates, revision-fenced move/resize/complete operations, and peer sharing; this change keeps class selection from bypassing that model.
