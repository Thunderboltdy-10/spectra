## What landed

- Artifact Library/tree/search reads use bounded `spectraArtifactSummaries`
  rows. Revision identity and hashes now live in indexed
  `spectraArtifactRevisionFacts`, keeping content-checkpoint churn out of the
  hot summary row while retaining `updatedAt` for modified-time ordering.
- Run tabs and result-card/recent reads use versioned compact projections and
  targeted indexes. Run lifecycle triggers update tab and card-summary rows
  directly, without reopening canonical plan, context, evidence, or card
  payloads.
- Card and tab projections allow long-running status/detail text to be bounded,
  but preserve clarification option keys and titles byte-for-byte. The client
  truncates only display copy; selection and continuation send the canonical
  value. Choice requests accept any number of options at or above the existing
  two-option minimum, including batch choices.
- Legacy rows have bounded repair fallbacks during migration. Once the result
  card fence is complete, list/recent reads do not probe the canonical card
  tail merely because a page is short.
- The local launcher reuses a running saved self-hosted Convex deployment when
  cloud-project metadata is unavailable, while still attaching the current
  source with the self-hosted admin endpoint. This fixes the reported
  `npm run local:start:all` failure without creating a second database.

counters.

| Read path | Canonical fixture | Compact/current result |
| --- | ---: | ---: |
| Artifact body vs summary | 728,802 B vs 685 B small body | 2,550 B large summary; 1,189 B small summary |
| Run body vs tab | 284,203 B canonical run | 31,634 B stored tab; 32,259 B compact tab response |
| Card body vs summary | 156,677 B canonical card | 3,009 B stored card summary; 2,811 B compact card response |

The larger tab value is intentional: the W8 lifecycle fixture retains 12
clarification options, including exact long keys/titles, so continuation
identity is not lost to display truncation. The measurement still excludes the
large plan/context payload markers from compact reads.
