## Scope completed

This slice connects the existing editor/command/K-bar/capability seams to actual linked DOCX operations for bounded equations and retained DrawingML images.

- Supported inline and block equations now insert through the native DOCX writer with deterministic OMML. Block equations can switch inline/display form and persist left/center/right paragraph alignment without changing source or retained advanced OMML.
- Imported equations carry exact `ommlXml` plus source provenance. Unchanged retained subtrees are copied exactly; changed supported source regenerates native OMML; unsupported syntax remains source-preserved and returns a diagnostic instead of flattening.
- Native images carry a stable DrawingML occurrence identity (`docPr`-based), separate from the media part. `delete-image` targets one occurrence, removes the drawing run precisely, releases the media relationship/part only when no XML owner still uses it, and can restore a surviving shared-media occurrence for undo.
- Projection and editor image nodes retain occurrence identity through JSON/Tiptap round trips. The semantic digest ignores package locators and raw OMML transport metadata while comparing canonical authored meaning.
- Equation insertion, equation layout, and image removal now advertise their real native deltas in capability IR and command bindings; the prior blanket refusals for these implemented basics are removed.

## Sequential acceptance steps

1. Open a disposable linked DOCX containing bold text and a native image, insert an inline supported equation between them, save, reopen in Word, and confirm the text formatting, equation, image, and image identity remain intact.
2. Insert a block matrix/root equation between two paragraphs, switch its placement and alignment without changing source, save/reopen, and confirm it remains native OMML with the requested layout.
3. Delete one of two visible occurrences sharing the same media bytes, undo, then save/reopen; confirm only the selected occurrence disappears, the shared media remains while referenced, and undo restores both occurrences without flattening.

## Material limits

This is a bounded school-math grammar, not a general TeX engine. Unsupported syntax, complex Word wrapping/anchoring, fields/revisions/comments, advanced section structure, and non-PNG/JPEG authored media remain preserve-only or explicitly refused. Package tests do not claim Microsoft Word GUI rendering or a live Bridge/provider deployment; no hosted deployment or original synced file was touched.
