## Root causes repaired

- Streaming upload previously trusted a completion path without independently verifying streamed byte count and digest; the route now attests the exact stream and quarantines a short/mismatched upload.
- Valid Office packages with transparent ZIP suffixes were rejected by package-boundary assumptions; the parser now trims only valid zero padding while preserving original upload bytes.
- DOCX data-URL images were ephemeral across editor/save/reopen; imports now materialize durable artifact assets and preserve inline image schema through Yjs/native projection.
- Metadata-only collaboration saves could drop page chrome; native metadata replacement now carries page setup and user edits are distinguished from remote reconciliation.
- Pinned assets were not readable after source deletion under the retained authority boundary; asset reads now authorize only the surviving pinned version and its referenced asset.
- Provisional placement expiry and source tombstoning could race a legitimate pinned placement; pinned provisional embeds survive source deletion until unpinned.
- Local Convex deletion cursors used Node-only `Buffer`; the scheduled worker now uses runtime-safe base64url encoding.
- Reference-card chrome exposed too many implementation states; visible copy is reduced to the source title and actionable warning, with state retained accessibly.

## Material limits

This is a bounded local acceptance, not a claim of general Office parity. Microsoft Word GUI rendering and a live Bridge/native reopen were not available for this run; package/native projection and editor reopen tests are reported as such. Unsupported Word fields, revisions, comments, complex section structure, anchored/wrapped authoring, and non-PNG/JPEG authored media remain preserve-only or explicitly refused.
