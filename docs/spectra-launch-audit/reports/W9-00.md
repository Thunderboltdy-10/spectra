## Word no-op repair

The compact → editor/Yjs → projection inference → materialize/reopen seam now compares authored semantics rather than native package metadata. Exact equation carry is restored only from the bound prior projection when the incoming LaTeX is unchanged; it is never recovered from a latest or unrelated revision. Image occurrence identity and image operations remain explicit, so image insert/delete/replace/update and same-cardinality reorder remain meaningful. Rich run boundaries are preserved when formatting or hyperlink marks differ, and native trailing padding whitespace does not become a false edit.

The focused regression is `does not rewrite compacted native subtrees across the editor seam` in `src/features/spectra/__tests__/docx-lens.test.ts`. It covers:

- supported and unsupported equations, including exact OMML carry;
- a rich table cell containing surrounding prose and an equation;
- two occurrences sharing one native image part;
- zero inferred operations and byte-identical materialization for unchanged compacted content;
- one neighboring paragraph replacement, with only `word/document.xml` changed and the neighbor preserved; and
- refusal of a stale-base concurrent merge when native anchors were not persisted.

The existing image replacement/deletion tests also remain green after the semantic comparison change; image-only deltas are not suppressed merely because visible paragraph text is unchanged.
