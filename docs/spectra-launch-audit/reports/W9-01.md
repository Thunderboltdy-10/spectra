# W9-01 — Student resources and local rehearsal

## Scope

Implemented on private branch `codex/w9-01-student-resources` from reviewed commit `05d9d6e0`. No shared browser/runtime or hosted/prod state was used.

## Design Read

This is an operate-mode extension of the existing School shelf. The change keeps the incumbent row/list vocabulary and restrained density, with one clear keyboard-accessible `Import to Library` action for ordinary students. Loading, retry, updated-revision, retained-copy, and failure states are explicit. The source URL is not a client navigation target; provider routing and credentials remain server-side. Provenance and recovery copy are prioritized over visual novelty.

## Implemented seams

- Added the account/school/source-revision scoped `managebacResourceImports` receipt ledger. It fences source record identity, selected-class access, account/school ownership, replay, retry, source revision updates, and live provider unavailability.
- Added `beginResourceImport`, `attachResourceImportArtifact`, `completeResourceImport`, and `failResourceImport` mutations. Adoption rechecks the selected class, current source hash, source state, and artifact ownership.
- Added a verified on-demand ManageBac binary capability. The route uses the server-side integration manifest and secret, rejects unresolved/cross-origin routes and redirects, bounds response bytes/time, checks PDF/Office signatures, and fetches bytes only after explicit import.
- Reused real `spectraArtifacts:createImportedResource`, `spectraArtifacts:create`, `payloads:issueUpload`, `payloads:put`, and `replicas:attachPortablePayload` seams. Office bytes are opened through the existing DOCX/XLSX/PPTX lenses before native artifact creation and the original package is retained as the portable payload.
- Added one shared typed action across human School rows, K-bar, application command registry, semantic bus, Spectra shell, and AI tool `import_managebac_resource`. The action accepts a provider record identity, never a caller URL or provider user id.
- School resource rows now show `Import to Library`, loading, saved/retained-copy, and updated-copy states. Provider links are no longer exposed as arbitrary client navigation.
- Extended the local provider fixture with counted binary requests, valid PDF/Office bytes, missing/revoked/updated/slow controls, and redirect behavior.
- Added `scripts/local/student-resource-rehearsal.mjs` plus the `localStudentRehearsal` Convex seam. Snapshot/apply/restore are local-deployment-only, require normal verified platform-operator identity resolution, preserve the real target account, create no account or email delivery, and restore membership context idempotently.

## Local rehearsal commands

```text
node scripts/local/student-resource-rehearsal.mjs snapshot --student-email <real-local-student> --school-id <local-school-id>
node scripts/local/student-resource-rehearsal.mjs apply --student-email <real-local-student> --school-id <local-school-id> --role student
node scripts/local/student-resource-rehearsal.mjs restore --student-email <real-local-student> --school-id <local-school-id>
```

The helper refuses non-local Convex deployments, production mode, unsafe snapshot paths, unverified identities, and cross-school active memberships.
