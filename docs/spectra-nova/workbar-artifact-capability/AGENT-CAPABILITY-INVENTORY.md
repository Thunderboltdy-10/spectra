# Agent Foundry Capability Inventory

**Scope:** P12.I6 Agent Foundry depth.
**Evidence date:** 2026-08-31.
**Named leaders:** OpenAI Agent Builder/Evals, LangSmith evaluation and deployment comparison, Anthropic skill authoring workflows.
**Code truth inspected:** `components/agent-foundry.tsx`, `agents/foundry/{evaluation,routing,skills}.ts`, `artifacts/{registry,schemas}.ts`, `artifacts/skills/agent.ts`, and the P3 capability IR.
**IR census:** 7 Agent definitions before P12.I6; 42 after implementation (35 net new). Every `ship` row below resolves through `CapabilityDefinition`; local-only controls are not closure.

Legend: `ship` = implemented or completed in I6; `refuse honestly` = visible plain-language boundary; `defer-with-owner` = intentionally later, with a named owner.

## I6 implementation evidence

- `capabilities/studio-agent.ts` owns all 42 definitions; the seven stable P3 ids remain intact and `studios.ts` has no Agent registry.
- `components/agent-foundry.tsx` binds authoring, evaluation, comparison, release, routing-preview, and refusal controls to the semantic ids; `artifacts/skills/agent.ts` exposes the same depth to the AI plane.
- `artifacts/schema/agent.ts` owns schema version 2 and an explicit, idempotent v1-to-v2 Foundry migration registered by the artifact manifest.
- `p12-agent-timetable-depth.test.ts`, capability conformance, the capability ghost gate, scoped ESLint, TypeScript, copy, design-token, and architecture gates pass.
- P12.V2 independently demonstrates every `ship` row, every refusal sentence, and narrow-width/keyboard behavior; I6 claims implementation, not acceptance.
