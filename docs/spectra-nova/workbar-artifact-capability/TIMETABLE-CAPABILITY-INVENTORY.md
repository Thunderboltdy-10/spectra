## I6 implementation evidence

- `capabilities/studio-timetable.ts` owns all 47 definitions; the eight stable P3 ids remain intact and `studios.ts` has no Timetable registry.
- `components/timetable-studio.tsx` binds layer, event, overlay, recurrence, import/export, and print controls to the semantic ids; `artifacts/skills/timetable.ts` exposes the same depth to the AI plane.
- `artifacts/schema/timetable.ts` owns schema version 2 and an explicit v1-to-v2 migration that keeps shared/source truth in the artifact while personal layers, display choices, and overlays use the existing user-state seam.
- `p12-agent-timetable-depth.test.ts`, timetable shared/view coverage, capability conformance, the capability ghost gate, scoped ESLint, TypeScript, copy, design-token, and architecture gates pass.
- P12.V2 independently proves every `ship` row, every refusal, narrow-width/keyboard behavior, and that P13's `calendarItems` temporal-truth seam remains unchanged; I6 claims implementation, not acceptance.
