# P8 — The Release Gate

**Goal:** the finale that every prior program postponed, run as a gate rather than a hope (N12's intent, absorbed). Nothing new is built here except fixes; the phase exists to prove — adversarially, at scale, over time — that the composed product meets PRODUCT §6. Its output is a written release verdict.

**Prerequisites:** P1–P7 accepted. **Architecture:** all. This phase is verification-led: V-units drive; the I-unit is a fix window.

**Difficulty (PROCESS §4):** V1 = Hard / GPT 5.6 Sol xhigh. I1, V2 = Medium-thinking / Grok 4.6 High (V2 may be Sol if Pablo wants a harder grader than the fix window).
