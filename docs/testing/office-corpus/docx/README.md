# DOCX fidelity corpus

This directory preserves provenance, expected-behavior metadata and historical
evaluation results for the optional local Office corpus. Binary test packages
are kept locally under `fixtures/office/`; see [the testing guide](../../../TESTING.md).

These are hostile public test assets from the Microsoft Open XML SDK repository (MIT), used locally as binary fixtures rather than generated by Spectra. `corrupt.docx` is a deliberately truncated copy used only for failure handling. Each document has a `.fixture.json` sidecar naming its expected fidelity classes. Sidecar `contains` claims are verified against the package bytes in the L1 seam-contract suite; a claim the bytes do not support is a test failure. The harness never executes macros or embedded objects.

Source repository: https://github.com/dotnet/Open-XML-SDK

The committed `harness-report.json` is regenerated by `npm run fidelity:docx`.
