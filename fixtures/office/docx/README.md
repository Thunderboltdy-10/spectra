# DOCX fidelity corpus

These are hostile public test assets from the Microsoft Open XML SDK repository (MIT), retained as binary fixtures rather than generated by Spectra. `corrupt.docx` is a deliberately truncated copy used only for failure handling. Each document has a `.fixture.json` sidecar naming its expected fidelity classes. The harness never executes macros or embedded objects.

Source repository: https://github.com/dotnet/Open-XML-SDK

The committed `harness-report.json` is regenerated by `npm run fidelity:docx`.
