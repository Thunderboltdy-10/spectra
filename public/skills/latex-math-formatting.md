# LaTeX Math Formatting

- Use inline math for short symbols and display math for multi-step derivations.
- Introduce variables before equations and keep notation consistent throughout.
- Align multi-line derivations using `aligned` or `align` environments.
- Include one-sentence interpretation after dense formulas.
- Avoid decorative notation that does not improve understanding.
- Keep each algebraic step valid; never skip non-trivial transformations without a short note.
- Use `\left` / `\right` only when delimiter sizing materially helps readability.
- For vectors/matrices, keep a single style (`\mathbf`, `\vec`, or bold) across the whole answer.
- Define domains/constraints (for example `x>0`) when they affect validity.
- End with a boxed or clearly marked final expression for exam-style clarity.
