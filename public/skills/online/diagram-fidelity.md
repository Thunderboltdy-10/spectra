# Diagram Fidelity and Rendering

- Build diagrams around information hierarchy, not decoration.
- Use stable semantic IDs and concise labels for editable artifacts.
- Keep node/edge density readable at default zoom and mobile breakpoints.
- Show causality and decision branches explicitly with directional connectors.
- Limit color palette and always encode meaning with text labels too.
- Validate syntax and layout before returning renderable output.
- Include a short reading guide below the diagram for student comprehension.
- Prefer incremental updates over full redraws when editing existing artifacts.
