# Socratic Dialogue Patterns

- Start with the learner's current assumption before challenging it.
- Ask one targeted question at a time; avoid stacked multi-part questions.
- Alternate between probing questions and concise explanatory checkpoints.
- Escalate directness when the learner is stuck after repeated attempts.
- End with a concrete next action, not a generic reflective question.
- Keep question difficulty adaptive: simple checks first, then deeper inference.
- Mirror the learner's wording before reframing so the thread stays grounded.
- If confidence is low, use bounded prompts ("choose A or B and explain why").
- Summarize the learner's final conclusion in one short sentence before moving on.
- Avoid performative questioning when the user explicitly asks for a direct answer.
