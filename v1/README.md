# Spectra V1 — File Map (v0.2)

- `workspace.html` — shell + script tags
- `data.jsx` — sample workspaces, items, quick-starts
- `icons.jsx` — stroke icon set
- `items.jsx` — Item component: glance/touch/bloom renderers per kind
- `widgets.jsx` — Timer / Stopwatch / Planner / Quick-note widgets
- `chrome.jsx` — TopRail, AtlasStrip, ViewModeToggle, Minimap, Tray, CommandBar, Spotlight, ZoomControl, EdgeHubs
- `app.jsx` — main App: pan/zoom, working set, focus, glow, quick-starts
